# Modelagem de Sistemas — Material do Curso

Material de apoio da disciplina **Modelagem de Sistemas**, do curso **Técnico em Desenvolvimento de Sistemas** (Turma 103513). Aqui você encontra, para cada aula: a apostila do aluno e os slides usados em sala.

**Carga horária:** 82h (20 aulas de 4h + 1 aula de 2h)
**Período:** 03/09/2026 a 27/11/2026

## Como usar

Antes de cada aula, baixe a pasta correspondente (`Aula NN - DD-MM-AAAA`). Ela já vem com tudo que você vai precisar naquele dia: apostila e slides.
